# ⛵ SAILINGSTONE QUEST

세일링스톤 AI-BI 인턴 6기 수습 시뮬레이션.
가상 고객사 **(주)한결정밀**(전기차 부품 제조)의 공장 데이터로 SQL 기초부터 세일링스톤 공고가 요구하는 수준
(복잡한 조건·테이블 조합·비즈니스 로직)까지 올라가고, 마지막엔 Python 자동화와 경영진 KPI PoC로 정규직 전환에 도전합니다.

> 회사명은 실제 지원처를 빌린 시뮬레이션 설정이고, 고객사·인물·데이터는 전부 가상입니다.

---

## 1. 시작하기

**준비물**: Python 3.8 이상. pandas는 6장부터 필요합니다 (`pip install pandas`).

```bash
# 압축 푼 폴더에서 (VS Code 터미널 추천)
python play.py        # 맥은 python3 play.py, 윈도우는 py play.py 도 가능
```

1. 이름을 입력하면 첫 티켓이 열리고 `workspace/ch0/0-1.sql` 파일이 생깁니다.
2. VS Code에서 그 파일을 열면 맨 위에 요청 내용이 주석으로 적혀 있어요.
3. 맨 아래에 쿼리를 쓰고 저장 → 터미널에서 `python play.py check`

## 2. 한 티켓의 흐름

```
python play.py          # 지금 상태와 현재 티켓
python play.py ticket   # 요청 내용 크게 보기 (파일 맨 위에도 있음)
  … 파일 작성 · 저장 …
python play.py run      # 결과 미리보기 (채점 X)
python play.py check    # 채점 → 통과하면 다음 티켓 파일이 자동으로 준비됨
```

막혔을 때 추천 순서: `run`으로 내 결과 보기 → `schema`로 컬럼 확인 → `hint`

## 3. 명령어

| 명령 | 설명 |
|---|---|
| `python play.py` | 현재 상태, 장별 진행, 배지 |
| `ticket` | 현재 티켓 보기 |
| `run` | 작성한 쿼리·함수 실행 결과만 보기 |
| `check` | 채점 |
| `hint` | 힌트 (3단계) |
| `solution` | 힌트 3개를 다 본 뒤 모범 답안 |
| `schema [테이블]` | 테이블 정의서, 연결 키, 컬럼 설명과 샘플 |
| `sql "SELECT ..."` | 자유 쿼리 실행 (인자 없으면 `workspace/scratch.sql`) |
| `map` | 전체 티켓 지도 |
| `exam` | 현재 장의 승급 시험 (통과하면 남은 티켓 면제) |
| `daily` | 평일 5분 복습 |
| `back` | 시험·복습 모드에서 원래 진행으로 |
| `reset` | 진행 초기화 |

## 4. 주말 플랜 (수료 전 5주말)

| 주말 | 날짜 | 범위 | 티켓 | 예상 시간 |
|---|---|---|---|---|
| 1 | 10/10~11 | 0~2장 기본 조회 · 집계 | 17 | 2~3시간 |
| 2 | 10/17~18 | 3장 JOIN | 9 | 2~3시간 |
| 3 | 10/24~25 | 4장 서브쿼리 · CASE · CTE | 8 | 3시간 |
| 4 | 10/31~11/1 | 5장 윈도우 함수 · KPI · 예지보전 | 8 | 3~4시간 |
| 5 | 11/7~8 | 6장 Python 자동화 · 정합성 + 7장 PoC | 10 | 4시간 |

4장(서브쿼리·CASE·CTE)까지 끝나면 공고의 "복잡한 조건, 테이블 조합, 비즈니스 로직 구현" 구간을 통과한 거예요.
이미 아는 장은 `exam`으로 승급 시험부터 보면 건너뛸 수 있어요.

## 5. 보상 규칙

- **원샷 보너스**: 첫 시도에 힌트 없이 통과하면 +20%
- **힌트**: 1개당 -20% (최대 -60%)
- **모범 답안**: 보상 20%, 그리고 평일 복습 목록에 올라가요
- **승급 시험**: 장 마지막 시험을 먼저 통과하면 남은 티켓 면제 (각 50%)
- SQL 문법 오류·실행 오류는 오답 횟수에 세지 않아요
- 틀리면 원인 유형을 알려 주고, 두 번째부터는 "내 결과에만 있는 행 / 정답에만 있는 행" 예시를 보여 줘요
- 대표적인 실수(정수 나눗셈, COUNT(*) 함정, 팬아웃 등)는 그 실수를 콕 집어 알려 줘요

## 6. 평일 5분 복습 (강력 추천)

주말에만 하면 매번 5일 공백이 생기고, SQL은 손이 기억해야 하는 기술이라 그 사이에 꽤 빠져요.
평일에 `python play.py daily` 한 번이면 예전 티켓 하나를 빈 파일에서 다시 풀게 됩니다. 5분이면 끝나요.

## 7. 팁

- `data/hangyeol.db`를 VS Code의 SQLite 확장(예: SQLite Viewer)으로 열면 데이터 감 잡기에 좋아요.
- 고객사 DB는 읽기 전용으로 열려서, 어떤 쿼리를 써도 데이터가 망가지지 않아요.
- `data` 폴더를 지우고 다시 실행하면 똑같은 데이터로 재생성돼요.
- `workspace` 폴더에 내 풀이가 전부 남아요. 학습 기록으로 GitHub에 올린다면, 게임 자체는 AI로 만든 연습 도구라는 점을 README에 밝혀 두는 게 좋아요.
